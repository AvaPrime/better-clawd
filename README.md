## Privacy & Telemetry

Telemetry is disabled by default. This ensures that user activities remain private unless explicitly allowed by the user. If you want to enable telemetry, you could set the `DISABLE_TELEMETRY` environment variable to false.

The telemetry infrastructure remains in place, but all data sinks are disabled by default to protect user privacy.
